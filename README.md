# Partiel design pattern

App en TS pour impressions de doc officiels (CNI, Passeport, Carte Vitale) avec design patterns.

## Installation

```bash
bun install
```

## Lancement

```bash
bun run src/index.ts
```

## Design patterns utilisés

### Template Method — `DocumentAImprimer.ts`

Coeur de l'app, Template Method définit le squelette de l'algorithme d'impression, peu d'autre choix dans ce cas de figure.

### Adapter — `CarteVitaleAdapter.ts`

Pas possible de modifier le code source CPAM, on adapte donc `CarteVitaleCpam` pour qu'il implémente l'interface commune `IDocumentImprimable`.

### Factory — `DocumentFactory.ts`

L'app n'instancie jamais directement `CniDocument`/`PasseportDocument`/`CarteVitaleDocument` tout passe par `creerDocument(type, personne)`,de facon centralisé.

### Dependency Injection — `Imprimante.ts`

L'imprimante ne devant rien connaitre du métier , elle est injectée dans les documents à imprimer. Cela permet de changer facilement d'imprimante.
